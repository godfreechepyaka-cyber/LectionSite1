# Домашнее задание: LibreOffice Writer — 9 вариантов

> Каждый студент выполняет **один** вариант. Сдача — к следующему занятию.
> Формат сдачи: файл `.odt` + скриншоты (при необходимости) + краткий отчёт.

---

## Карточка 1. Документ с автооглавлением

| Поле | Содержание |
|---|---|
| **Задание** | Создайте документ 3–4 страницы на тему «Моя будущая профессия». Минимум 3 главы и 6 подглав. Примените стили заголовков и создайте автоматическое оглавление. |
| **Вводные данные** | Структура: Введение, Глава 1 (2 подглавы), Глава 2 (2 подглавы), Глава 3 (2 подглавы), Заключение. |
| **Подробное решение** | 1. Запустите Writer. 2. Наберите текст. 3. Примените стиль «Заголовок 1» к главам, «Заголовок 2» — к подглавам. 4. Установите курсор после титульного листа. 5. Вставка → Оглавление и указатели (Insert → Table of Contents and Index) → Оглавление. 6. Настройте уровни 1–2. 7. ОК. 8. Сохраните как `.odt`. |
| **Ответ** | Документ с автособираемым оглавлением и номерами страниц. При изменении заголовков — правый клик на оглавлении → «Обновить» (Update). |

---

## Карточка 2. Настройка интерфейса Tabbed Compact

| Поле | Содержание |
|---|---|
| **Задание** | Настройте интерфейс Writer в режиме Tabbed Compact. Сделайте скриншот и опишите вкладки и отличия от Standard Toolbar. |
| **Вводные данные** | LibreOffice Writer открыт. Текущий интерфейс: Standard Toolbar. |
| **Подробное решение** | 1. Вид → Пользовательский интерфейс (View → User Interface). 2. Выберите Tabbed Compact. 3. «Применить к Writer». 4. Скриншот (Print Screen). 5. Опишите: вкладки (Файл, Главная, Вставка, Макет, Ссылки, Рецензирование, Вид), отсутствие строки меню, группировку команд. |
| **Ответ** | В режиме Tabbed Compact строка меню скрыта, команды сгруппированы по вкладкам. Отличие от Standard Toolbar: компактность, сходство с MS Office. |

## Карточка 3. Таблица с вычислениями

| Поле | Содержание |
|---|---|
| **Задание** | Создайте таблицу «Успеваемость группы»: ФИО, Математика, Физика, Информатика, Средний балл. 5 студентов. Вычислите средний балл формулами Writer. |
| **Вводные данные** | 5 студентов, оценки по 3 предметам (2–5). |
| **Подробное решение** | 1. Таблица → Вставить таблицу (Table → Insert Table) — 4 колонки, 6 строк. 2. Заполните данные. 3. В ячейке «Средний балл» первого студента: Таблица → Формула (Table → Formula). 4. Введите `=(B2+C2+D2)/3`. 5. Скопируйте для остальных. 6. Оформите границы и фон шапки. |
| **Ответ** | Таблица с автоматически вычисленным средним баллом. Формулы редактируются через правый клик → «Редактировать формулу» (Edit Formula). |

## Карточка 4. Изображение с обтеканием

| Поле | Содержание |
|---|---|
| **Задание** | Создайте документ с текстом (2–3 абзаца) и вставьте изображение. Настройте обтекание «По контуру» (Wrap → Through). Добавьте подпись. |
| **Вводные данные** | Любое изображение из папки «Изображения». Текст произвольный. |
| **Подробное решение** | 1. Наберите текст. 2. Вставка → Изображение (Insert → Image). 3. Правый клик → Свойства (Properties). 4. Вкладка «Обтекание» → «По контуру». 5. Вкладка «Положение» → «По центру». 6. Правый клик → Вставить подпись (Insert Caption). 7. Настройте нумерацию. |
| **Ответ** | Изображение с обтеканием, подпись «Рис. 1 — ...». |

## Карточка 5. Колонтитулы и нумерация страниц

| Поле | Содержание |
|---|---|
| **Задание** | Создайте документ 3 страницы. Верхний колонтитул — название, нижний — нумерация. На первой странице колонтитулы отсутствуют. |
| **Вводные данные** | Название: «Отчёт по практике». 3 страницы текста. |
| **Подробное решение** | 1. Вставка → Верхний колонтитул (Insert → Header and Footer → Header) → Стиль страницы по умолчанию. 2. Вставка → Нижний колонтитул (Footer). 3. В верхний введите «Отчёт по практике». 4. В нижний: Вставка → Номер страницы (Insert → Page Number). 5. Для первой страницы: Формат → Стиль страницы (Format → Page Style) → вкладка «Колонтитулы» → снять галочки. |
| **Ответ** | Документ с колонтитулами, первая страница без них. |

## Карточка 6. Стили для курсовой работы

| Поле | Содержание |
|---|---|
| **Задание** | Настройте стили: «Заголовок 1» — Times New Roman 16 пт, полужирный, по центру; «Основной текст» — TNR 14 пт, по ширине, отступ 1,25 см, интервал 1,5. Примените к документу. |
| **Вводные данные** | Текст курсовой (2–3 страницы). |
| **Подробное решение** | 1. Панель «Стили» (F11). 2. Правый клик на «Заголовок 1» → Изменить (Modify). 3. Вкладка «Шрифт»: TNR, 16 пт, полужирный. 4. Вкладка «Выравнивание»: по центру. 5. Аналогично — «Основной текст». 6. Примените стили. 7. Файл → Шаблоны → Сохранить как шаблон (File → Templates → Save as Template). |
| **Ответ** | Документ со стилями по требованиям. Шаблон сохранён. |

## Карточка 7. Шаблон делового письма

| Поле | Содержание |
|---|---|
| **Задание** | Создайте шаблон делового письма: шапка с логотипом, дата, адресат, обращение, текст, подпись. Сохраните как `.ott`. |
| **Вводные данные** | Организация: ООО «Пример». Адресат: Иванов И.И. Тема: «О сотрудничестве». |
| **Подробное решение** | 1. Новый документ. 2. Вставьте логотип. 3. Наберите текст. 4. Стили для форматирования. 5. Файл → Шаблоны → Сохранить как шаблон. 6. Категория «Мои шаблоны», имя «Деловое письмо». |
| **Ответ** | Шаблон `.ott`. При создании нового документа через Файл → Создать → Шаблоны (File → New → Templates) выбирается шаблон. |

## Карточка 8. Настройка панели инструментов

| Поле                  | Содержание                                                                                                                                                                                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Задание**           | Добавьте на панель команды «Экспорт в PDF» и «Вставить таблицу». Удалите «Печать». Скриншоты до и после.                                                                                                                                                                  |
