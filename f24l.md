📚 Если что-то вспомните

Все ключевые файлы, которые стоит держать в голове:

    .github/workflows/deploy.yml — CI/CD.

    quartz/quartz.config.yaml — настройки сайта (baseUrl, pageTitle, ignorePatterns).

    pnpm-workspace.yaml — определение монорепозитория.

    slides/f2l3/package.json — параметры сборки конкретной презентации (флаг --base).

На будущее — памятка

Для каждой новой презентации (F2L4, F2L5):

    Создаёте папку slides/f2l4/ с slides.md.

    В slides/f2l4/package.json прописываете:
    json

    "build": "slidev build slides.md --base /LectionSite1/slides/f2l4/"

    В корневом package.json дописываете:
    json

    "build:slides": "pnpm --filter f2l3 build && pnpm --filter f2l4 build"

    В quartz/content/index.md добавляете ссылку:
    markdown

    - [F2L4](/slides/f2l4/)

    Пуш — CI сам всё соберёт и задеплоит.

Для скриншотов:

    Кладёте PNG в slides/f2l4/screenshots/.

    В markdown ссылаетесь относительно: ![...](./screenshots/имя.png).

    Никогда не используйте абсолютные пути /screenshots/... — они ломают сборку.
